## Snippets for the interpreter, compared with V8 by InterpreterOracleTest. `node tools/strudel-ref/interpreter-oracle.mjs`
## runs each as the body of a function in Node (strict mode) and writes oracle.json; the Kotlin interpreter must print the
## same text: the value (prelude.js show()), or `THROW <name>: <message>`. Nothing here uses a library (no Math, no
## Array.prototype.map, no JSON): only the language and the helpers isArray/keys/hasOwn of prelude.js.
## Format: `### <name>` then the code; `### <name> !json` then one JSON string literal. `## ` lines are comments.
