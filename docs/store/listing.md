## English (en-US)

### Title
Cosic: Live Coding Music

### Short description
Write patterns in code and hear them play. Made for touchscreens.

### Full description
Cosic is a live-coding music app. You write a few lines of code, press Play, and a pattern of drums, notes and effects starts playing. Change the code while it plays and the music follows.

It is built for a phone: the keyboard has a row of keys made for code, and a second row that moves the cursor and grows or shrinks a selection one piece of code at a time, so you never have to place a cursor on a tiny character with your finger.

LEARN BY DOING
- Ten interactive lessons, step by step, each one a small program you play and change: cycles, mini-notation, notes and scales, sound, transformations, visuals, performing live.
- Six examples to open, play and take apart.
- Your own sketches are saved on the device.

WRITE ON A TOUCHSCREEN
- A symbol row with the characters code needs: quotes, brackets, parentheses, dot, tab, undo and redo.
- An edit row: move by character or by word, expand or shrink the selection by syntax, and work on whole lines (duplicate, comment, move, delete).
- Autocomplete above the keyboard while you type.
- Sliders drawn inside the code to change a value with your thumb.

SEE AND HEAR WHAT YOU WRITE
- The steps that sound light up in the code while the music plays.
- Piano roll, oscilloscope, spectrum, spiral, pitch wheel and punch card drawn right under the line that makes them.
- A console for printed values and errors.

DOCUMENTATION AND SOUNDS AT HAND
- A searchable reference of functions, with an example and Insert buttons.
- A Sounds panel with drum machines, synths, drum kits and instruments, each with a preview.
- Import your own sample folders.

SHARE AND CONNECT
- Export what you play to an audio file.
- Share your code as text or as a web link, and import a link or code from the clipboard.
- Send notes to MIDI devices, or to an OSC receiver over your network.

Cosic has no account and no sign-in; the developer receives no data from the app. Some sounds are downloaded the first time they play, so an internet connection is needed for them.

The app shows ads. A single one-time purchase removes them.

Cosic is open source software under the AGPL-3.0 licence and is based on the Strudel project. The Credits screen in Settings lists the licences.

## Français (fr-FR)

### Titre
Cosic : musique en live coding

### Description courte
Écrivez des motifs en code et écoutez-les jouer. Conçu pour l'écran tactile.

### Description complète
Cosic est une application de musique en live coding. Vous écrivez quelques lignes de code, vous appuyez sur Lecture, et un motif de batterie, de notes et d'effets se met à jouer. Modifiez le code pendant la lecture : la musique suit.

Elle est pensée pour le téléphone : le clavier propose une rangée de touches faites pour le code, et une seconde rangée qui déplace le curseur et agrandit ou réduit une sélection morceau de code par morceau de code. Plus besoin de viser un minuscule caractère avec le doigt.

APPRENDRE EN FAISANT
- Dix leçons interactives pas à pas, chacune est un petit programme que vous jouez et modifiez : cycles, mini-notation, notes et gammes, son, transformations, visuels, jeu en direct.
- Six exemples à ouvrir, écouter et décortiquer.
- Vos propres esquisses sont enregistrées sur l'appareil.

ÉCRIRE SUR UN ÉCRAN TACTILE
- Une rangée de symboles avec les caractères dont le code a besoin : guillemets, crochets, parenthèses, point, tabulation, annuler et rétablir.
- Une rangée d'édition : déplacement par caractère ou par mot, sélection qui s'étend ou se réduit selon la syntaxe, actions sur les lignes entières (dupliquer, commenter, déplacer, supprimer).
- Autocomplétion au-dessus du clavier pendant la saisie.
- Curseurs dessinés dans le code pour changer une valeur du pouce.

VOIR ET ENTENDRE CE QUE VOUS ÉCRIVEZ
- Les pas qui sonnent s'allument dans le code pendant la lecture.
- Piano roll, oscilloscope, spectre, spirale, roue des hauteurs et carte perforée dessinés juste sous la ligne qui les produit.
- Une console pour les valeurs affichées et les erreurs.

DOCUMENTATION ET SONS SOUS LA MAIN
- Une référence des fonctions avec recherche, exemples et boutons Insérer.
- Un panneau Sons avec boîtes à rythmes, synthétiseurs, kits de batterie et instruments, chacun avec une écoute.
- Importez vos propres dossiers d'échantillons.

PARTAGER ET CONNECTER
- Exportez ce que vous jouez vers un fichier audio.
- Partagez votre code en texte ou en lien web, et importez un lien ou du code depuis le presse-papiers.
- Envoyez les notes à des appareils MIDI, ou à un récepteur OSC sur votre réseau.

Cosic n'a ni compte ni connexion : le développeur ne reçoit aucune donnée de l'application. Certains sons sont téléchargés à leur première lecture, une connexion internet est donc nécessaire pour eux.

L'application affiche des publicités. Un achat unique les supprime.

Cosic est un logiciel libre sous licence AGPL-3.0, basé sur le projet Strudel. L'écran Crédits, dans les réglages, liste les licences.
